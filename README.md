# Mike Kipngeno — Portfolio

This is a static portfolio website for GitHub Pages.

## Publish it free with GitHub Pages

1. Create/sign in to a GitHub account.
2. Create a new public repository named `portfolio`.
3. Upload `index.html` and `style.css`.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will provide your public portfolio link.

Replace the placeholder GitHub URL with your actual username once you have it.
